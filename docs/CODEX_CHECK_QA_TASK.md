# Codex на Ubuntu VM — приёмка тренировки и проверки

Рабочий каталог `/home/dvpot/projects/github/umnozhayka`. Источник истины — `dvpot/umnozhayka`, ветка `main`. Прочитай `AGENTS.md`, `README.md`, `docs/PLAN.md`, `docs/TELEGRAM_DEPLOY.md`, `docs/BOT_PROFILE.md` и Issue #3. Начни с `git status -sb` и `git fetch origin`. Синхронизируй чистый `main` через fast-forward, запиши точный SHA. При локальных изменениях сохрани их и используй отдельный checkout или worktree для проверки. Исправления оформляй отдельным PR с CI.

1. Выполни `npm ci && npm run check`. Раздай `dist/` локальным HTTP-сервером. В браузере проверь ширины 280, 320, 390, 768 и 1024 px без горизонтальной прокрутки. Проверь отсутствие вертикальной прокрутки в «Проверке» при 400×612 CSS px (узкое окно Telegram Desktop), 320×480 и 768×720. Запиши фактический CSS viewport, нижнюю границу «Проверить» и scrollHeight. В «Выбери ответ» и «Проверке» проверь, что верх кнопки «Сбросить» ниже карточки хотя бы на 12 CSS px и тень её не перекрывает. Сверь размер шрифта ответа в тренировке и проверке и центр стрелок относительно карточки. Проверь, что «100 из 100» не перекрывает выражение `10×10` на ширинах 320 и 400 CSS px. Сравни вертикальный размер и структуру карточки во всех режимах; проверь на 320 px доступность всех кнопок, включая прокрутку на невысоком экране.
2. В «Тренировке» проверь подсказку по нажатию на `?` и через 10 секунд, три варианта ответа, повтор после ошибки, стрелки и свайпы. Начни свайп поверх ответа и кнопок стрелок: задание должно поменяться один раз без активации элемента под концом жеста; обычные нажатия после этого должны работать. В «Выбери ответ» повтори жест поверх варианта, проверь, что ошибочный вариант не выбирается жестом, затем обычным нажатием проверь ответ. Выбери ×10, продвинься на второй пример и переключись в «Проверку». Первая проверка должна начать ×10 с первого примера.
3. В «Проверке» проверь ввод цифр, удаление последней, отсутствие системной клавиатуры при касании, недоступность проверки пустого ответа и перехода до оценки. На ×10 отправь `999` для `10×1`, нажми `1` и `0`. Поле должно показать `10` без подсветки до проверки, а счётчик ошибок не должен измениться. Для `10×2` отправь `29`, затем «Удалить» и `0`: должно получиться `20`. После перезагрузки с ошибкой проверь новый ввод физическими цифрами, включая цифру, равную прежнему однозначному ответу. Введённое число нейтрально до проверки. Для неверного `009` удаление стирает одну цифру до `00`, пока пример открыт. Нажатия цифр и Backspace после правильного ответа не меняют его. Проверь оба счётчика, скрытие клавиатуры после оценки, переход стрелкой, свайпом и клавишей →, невозможность повторной оценки или возврата к ответу. Для 10×10 введи `100`. Дойди до итога 10 примеров и сверь его с ответами. Проверь, что «Все» содержит 100 примеров, а перемешивание не даёт дублей.
4. Перезагрузи страницу после оценки и на итоговом экране. Проверь восстановление режима, счёта и позиции. Проверь отмену сброса, затем подтверждение сброса и нулевой счёт. Открой «Мой прогресс» на нижней панели. В меню `⋯` проверь, что остались настройки речи. До итогового экрана результат отсутствует. После полного прохода ×2 с одной исправленной ошибкой в блоке последнего прохода ожидается `9/10`, после чистого — `10/10`. Проверь сохранность результатов после перезагрузки и сброса текущего занятия. На 320×480 проверь, что нижняя панель не перекрывает клавиатуру, переключение экранов сохраняет черновик, а стрелки на экране прогресса не листают примеры. Заверши сохранённую проверку без флага tracksTableProgress: она должна показать обычный итог, не создавая оценку последнего прохода с неполной историей попыток. Переключись в «Тренировку» и проверь новый проход с первого примера.
5. Проверь фразы включения и выключения, тишину до перехода с открытого примера и первое раскрытие ответа после перезагрузки с сохранённым звуком. Для `Microsoft Irina - Russian (Russia)` при смене голоса ожидается «Привет, я Irina.». Проверь сохранённый выбор `umnozhayka:recorded` — он должен стать автоматическим. Без Web Speech API или без русских голосов настройки речи недоступны, значок ⓘ отсутствует, переходы и ответы работают без запроса MP3. При поздней загрузке русских голосов управление активируется.
6. На проверенном SHA выполни последовательно `npx tgcloud fetch`, `npx tgcloud status` и `npx tgcloud diff`. Сверь целевое приложение `8854507045` для `@umnozhayka_tgbot`, текущую ревизию и список файлов. Список ожидаемых изменений сверяй с текущим заданием выпуска. При неожиданных серверных изменениях выясни причину. Используй настроенный CLI, не запрашивай и не выводи секреты.
7. В этой задаче подготовь результат preflight. Публикация идёт по отдельному релизному шагу из `docs/TELEGRAM_DEPLOY.md`. Верни в чат точный SHA, команды и фактические результаты, браузер и размеры экрана, app ID, ревизию, список ожидаемых и неожиданных изменений, ссылку на PR при наличии исправлений. Отмечай отдельно то, что удалось проверить на реальном Telegram-клиенте.

## Прогресс аккаунта

- Открой «Мой прогресс» сразу после запуска. Данные загружаются вместе с игрой, переключение «Проверка» / «Выбери ответ» в блоке «Последний проход» не требует запроса. Кнопок «Обновить» и «Удалить статистику» нет.
- В «Тренировке» раскрой один ответ и пролистай следующий без просмотра. Ожидается 1/2. В «Выбери ответ» ошибись на первом примере: 0/1. Выбери верный вариант: 1/1. Повтори в «Проверке» с вводом ответа. До завершения таблицы итоги уже видны.
- Заверши ×2 в обоих режимах. Проверь, что фильтр показывает отдельные оценки с первой попытки. Затем заверши ×2 с более низким баллом, проверь замену предыдущего результата. Старый максимум не показывается как последний.
- На втором устройстве того же аккаунта проверь текущий пример, черновик, настройки и накопленные числа. Повтори вход и запись после сетевого сбоя, проверь отсутствие двойного начисления и сохранение порядка завершения при запоздалой отправке.
- В обычном браузере проверь ту же статистику после перезагрузки. При наличии второго аккаунта проверь изоляцию.
