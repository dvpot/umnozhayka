# Повтор ошибок текущего занятия — план реализации

> **Для исполнителя:** пройти шаги по порядку, тестировать до изменений production-кода.

**Цель:** дать ребёнку отдельный проход по примерам, где он ошибся в только что завершённой «Проверке» или «Выбери ответ».

**Архитектура:** список ошибок берётся из текущего завершённого состояния игры. Повтор — отдельная quiz-сессия с собственным списком ID; обычные занятия сохраняют полный набор 10/100 без повторов. Одно текущее состояние SQLite уже синхронизирует Telegram-аккаунт, поэтому архив или новая схема не нужны. Повтор не добавляет значения к обычным накопительным итогам; после нового неверного ответа повторный список содержит только неуспешные примеры.

**Стек:** ES modules, Node.js 22.13+, существующая SQLite Serverless и браузерная сборка.

**Спецификация:** `docs/PLAN.md`, issue #3; ограничения приватности `AGENTS.md`.

## Общие ограничения

- Обычный проход остаётся из 10 либо 100 уникальных заданий.
- Состояние повтора хранит только список пар вида `a×b` и текущий ответный прогресс; прошлые введённые значения не сохраняются.
- Синхронизация использует проверенный Telegram account context и одну текущую игру; новую таблицу БД не создавать.
- Перепрохождение ошибок не меняет накопительные счётчики и последние результаты таблиц.
- Интерфейс остаётся русским, клавиатура и текущие размеры главного экрана не меняются.

## Зоны особого внимания

- Подмена обычной сессии частичным списком: отклонять частичный список без явного `review`.
- Повторы и чужая таблица: проверять уникальность ID и соответствие множителю на клиенте и сервере.
- Миграции сессий: принимать сохранённые версии 2–5 без изменения поведения.
- Возобновление на другом устройстве: сохранять review-признак, ID списка, порядок и варианты ответа.
- Учёт ошибок внутри повтора: оставить ответы доступными для исправления, но не отправлять повторные счётчики в обычный прогресс.

### 3. Интерфейс повторного занятия

- Выводить «Повторить ошибки» на экране результата, если текущая проверка/викторина имела ошибки.
- Использовать ту же карточку и три варианта; повторять только задания с ошибками и не повторять их внутри списка.
- В списке следующего повтора оставлять только нерешённые задания; в режиме выбора перейти дальше можно лишь после правильного ответа.
- Не начислять review-ответы в обычные итоги.
