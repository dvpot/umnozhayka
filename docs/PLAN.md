# План «Умножайки»

## MVP v0.3 — UI и оформление бота

- Цветная однострочная фиксированная шапка, селектор «Все / ×1…×10» слева и кнопка пересекающихся стрелок без подписи справа.
- «Все» = 100 упражнений; таблица ×N = 10, N от 1 до 10. Два порядка, без повторов, после окончания повтор или следующий множитель.
- Ответ появляется автоматически спустя 10 секунд на открытом упражнении или сразу по нажатию на `?`. Нажатие останавливает таймер.
- Навигация свайпами и стрелками внутри карточки, без нижней панели. Клавиатура `←`/`→` для десктопа.
- Состояние сохраняется локально. Legacy v1 session при обновлении безопасно начинает новый цикл с прежней таблицей и режимом.
- Telegram `/start`: иллюстрация, русское приветствие, inline-кнопка Mini App; в BotFather — название, аватар, описания, команды и, при наличии настройки, иллюстрация описания.

## Релиз

1. Unit `node --test` и `npm run check`.
2. Browser QA на 280/320/390/768 px: не обрезаются ×10 и ответы `100`, нет горизонтальной прокрутки; стрелки, свайпы, shuffle, `?`, 10 секунд, finish, persist.
3. Проверить SDK `api.sendPhoto` и Web App inline кнопку, затем `tgcloud fetch/status/diff` перед push, real fetch/status после. Без force и без потерь чужих модулей.
4. Live `/start` и Mini App с телефона — подтвердить отдельно. После выполнения обновить Issue #2.

## Позже — не включено в v0.3

- Выбор правильного ответа с вариантами.
- Локальная статистика изученных таблиц и удаление данных.
- Повтор сложных примеров отдельным режимом.
- Сложение, вычитание и деление (по отдельной продуктовой спецификации).
- Темп ответов и звуки как опциональные настройки.
