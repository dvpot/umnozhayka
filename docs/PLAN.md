# План «Умножайки»

## MVP v0.2

- Однострочная закреплённая шапка.
- Выбор «Все», ×1–×9, случайный режим по галочке.
- По порядку / перемешивание Фишера—Йетса без повторений.
- Автоматический ответ после 10 секунд, если экран активен; таймер пауза при сворачивании.
- Свайпы, кнопки, клавиатура.
- Завершение и переход к следующей таблице ×1…×8.
- Локальное безопасное восстановление позиции и режима, без профиля и сервера.

## После первого реального запуска

1. Проверка интерфейса Telegram Android и iOS и узких экранов.
2. Добровольный режим «Выбери ответ» без штрафов.
3. Локальный прогресс изученных таблиц с ручным сбросом; без рейтингов детей.
4. Настройка темпа ответа (5, 10, 15 секунд), без навязчивых звуков.
5. При отдельном решении владельца — синхронизация через Telegram Serverless, с предварительным анализом приватности детей.

## Критерии приёмки

- node --test — успешно;
- корректные 81/9 уникальных примеров в обоих режимах;
- браузерные проверки на 320–768 px, свайпы, реальный таймер;
- запуск из BotFather Menu Button в Telegram;
- Telegram Serverless deployment подтверждён CLI, не предположен; перед проверкой `status`/`diff` получен свежий снимок командой `tgcloud fetch`.
