# Оформление Telegram-бота @umnozhayka_tgbot

Профиль и фото редактируются владельцем через @BotFather. CLI-токен Serverless не следует использовать для операций с профилем, если это не поддерживается официальным инструментом. Личные секреты в GitHub не помещать.

## Подготовленные изображения

- `app/assets/bot-avatar.png` — квадратная иконка для `/setuserpic` (512×512).
- `app/assets/welcome.png` — горизонтальная иллюстрация для сообщения `/start`.
- `app/assets/bot-avatar.svg`, `app/assets/welcome.svg` — редактируемые исходники.
- Для `Edit Description Picture` желательно из `welcome.png` получить 640×360 PNG, сохраняя текст внутри изображения.

## Поля BotFather

### Имя (`/setname`)
Умножайка — учим математику

### Короткое описание (`/setabouttext`, не более 120 символов)
Учим таблицу умножения играя: примеры от 1 до 10, подсказки и удобное листание.

### Описание (`/setdescription`, не более 512 символов)
Умножайка — простая игра для изучения таблицы умножения.

Выбирай таблицу от 1 до 10, решай примеры по порядку или вразброс, открывай ответ нажатием или через 10 секунд. Перелистывай задания свайпами или стрелками. У каждого урока есть завершение — без спешки и соревнований.

Сейчас доступно умножение. Позже появятся сложение, вычитание и деление.

Нажми «Играть» и начни заниматься!

### Команды (`/setcommands`)
start - Открыть приветствие и кнопку запуска

### Меню (`/setmenubutton`)
- URL: `https://app8854507045.tgcloud.ai/`
- Название: `Играть`

### Аватар (`/setuserpic`)
Отправить `app/assets/bot-avatar.png` **как фото**, не как файл.

### Изображение описания
`/mybots` → `@umnozhayka_tgbot` → `Edit Bot` → `Edit Description Picture`. Загрузить подготовленное изображение 640×360; доступность меню зависит от версии BotFather.

## Проверки
- `/start` в личном диалоге показывает картинку, русский текст и кнопку «Открыть Умножайку».
- Нажатие кнопки открывает действующее Mini App, на 320 px ничего не обрезано.
- Перезапуск `/start` не создаёт записей в БД и не собирает детские данные.
- Если sendPhoto не сработал, отправляется текст с рабочей кнопкой; проблему фото необходимо диагностировать отдельно.
