# Codex: независимая проверка и запуск

Перед началом прочитать AGENTS.md, README.md, docs/PLAN.md, docs/TELEGRAM_DEPLOY.md и актуальный main репозитория dvpot/umnozhayka.

1. Независимо выполнить npm run check, браузерный smoke-test на мобильном viewport, проверить 10-секундный таймер, свайпы, корректное восстановление localStorage и отсутствие повторов.
2. Проверить действительную конфигурацию Telegram Serverless для @umnozhayka_tgbot. Если CLI авторизован, сначала выполнить `npx tgcloud fetch`, затем проверить bot identity, `status` и `diff`; статус и diff без свежего fetch отражают только локальный снимок. Публиковать лишь после подтверждения цели и отсутствия неожиданных удалений. После публикации проверить URL, `/start` и Mini App в Telegram. Если CLI Access token отсутствует, не запрашивать его в чате: указать владельцу точный путь в BotFather и дождаться локального `npx tgcloud login`.
3. При ошибках разработать исправления и открыть PR. Не дублировать существующую работу Primary.
4. Не запрашивать и не публиковать токены/данные детей в чат, Issues, PR и логах.
