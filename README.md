# Умножайка

Мини-приложение Telegram на русском языке для изучения таблицы умножения играя: [@umnozhayka_tgbot](https://t.me/umnozhayka_tgbot).

## Возможности исходников `main`

- «Все» — 100 уникальных выражений от `1 × 1` до `10 × 10`; отдельные `×1…×10` — по 10 выражений.
- По порядку либо вразброс без повторений. Перемешивание включается/выключается кнопкой в шапке; активное состояние подсвечивается.
- Режим выбирается в шапке: «Тренировка», «Выбери ответ» или «Проверка». В тренировке ответ можно открыть нажатием на `?` или через 10 секунд; в выборе ответа неправильные варианты отмечаются и отключаются, а листать можно после правильного ответа.
- В «Проверке» ученик вводит число цифровой клавиатурой под примером. После неверного ответа нажатие цифры начинает новый ввод, а «Удалить» стирает последнюю цифру прежнего ответа. Можно исправить ответ или перейти дальше; «Верно» считает принятые правильные ответы, «Неверно» — все отправленные неправильные попытки, включая исправленные.
- В режимах «Выбери ответ» и «Проверка» счёт и сброс расположены под карточкой. Настройка озвучивания примеров, ответов и короткой обратной связи находится в меню `⋯`; для речи нужен доступный русский системный голос. Если среда не предоставляет такой голос, настройки речи недоступны.
- Карточка примера сохраняет размер между режимами. Свайп действует только внутри неё; при переходе между вкладками занятие сохраняет позицию.
- Таблица, порядок и позиция сохраняются для текущего режима; при смене режима или таблицы примеры и счёт начинают новый проход. Для «Проверки» в текущем проходе сохраняются отправленные ответы и количество ошибочных попыток.
- «Мой прогресс» загружается при запуске и обновляется по отдельным примерам. В «Тренировке» считаются раскрытые ответы из просмотренных или пролистанных примеров. В двух режимах с ответом считаются верные, включая исправленные, из примеров, на которые дан ответ. В блоке «Последний проход» можно переключать режим и смотреть балл с первой попытки по таблицам.
- В Telegram SQLite хранит прогресс, настройки озвучивания и одно текущее занятие аккаунта. При переносе восстанавливаются режим, порядок и пример, варианты ответа или черновик проверки. Если выбранного системного голоса на устройстве нет, используется доступный русский голос. Без Telegram данные сохраняются в браузере. Архив занятий, профили и контакты в БД не хранятся.

## Локальная проверка

Node.js 22.13+. `npm ci && npm run check`. Тесты охватывают 100/10 примеров, отсутствие дублей, восстановление состояния и операции с прогрессом в SQLite. Браузерную проверку выполняют отдельно.

## Telegram Serverless

Последняя подтверждённая публикация — Serverless revision `13`, SHA `028720a84e9dfa87d88fab721b7a3e4e53c9c88f` (PR #31, отчёт PR #32). Владелец подтвердил продолжение игры на двух устройствах. Приложение: <https://app8854507045.tgcloud.ai/>. История и результаты проверок — в [журнале публикаций](docs/TELEGRAM_DEPLOY.md).

Перед выпуском с БД следуй [порядку выкладки](docs/CODEX_RELEASE_CURRENT_MAIN_TASK.md): сначала серверные модули и проверенная миграция, затем статика. Перед каждым push выполни `npx tgcloud fetch`, `npx tgcloud status`, `npx tgcloud diff` и проверь app ID. После push проверь фактическую revision.

Username бота CLI не показывает. Для подтверждения, что сохранённая CLI-связь относится к `@umnozhayka_tgbot`, владелец сверяет app ID с настройками Serverless именно этого бота в BotFather.

Инструкции: [Telegram deployment](docs/TELEGRAM_DEPLOY.md), [оформление бота](docs/BOT_PROFILE.md), [независимая QA](docs/CODEX_CHECK_QA_TASK.md), [выпуск текущего main на Ubuntu VM](docs/CODEX_RELEASE_CURRENT_MAIN_TASK.md).

Файлы оформления: `app/assets/bot-avatar.png`, `app/assets/welcome.png` и SVG-исходники. Владелец подтвердил настройку бота и проверку Mini App в Telegram 4 ноября 2026 года. Отдельная проверка доставки `/start` с картинкой не зафиксирована.
