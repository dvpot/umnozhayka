# Умножайка

Мини-приложение Telegram на русском языке для изучения таблицы умножения играя: [@umnozhayka_tgbot](https://t.me/umnozhayka_tgbot).

## Возможности исходников `main`

- «Все» — 100 уникальных выражений от `1 × 1` до `10 × 10`; отдельные `×1…×10` — по 10 выражений.
- По порядку либо вразброс без повторений. Перемешивание включается/выключается кнопкой в шапке; активное состояние подсвечивается.
- Режим выбирается в шапке: «Тренировка», «Выбери ответ» или «Проверка». В тренировке ответ можно открыть нажатием на `?` или через 10 секунд; в выборе ответа неправильные варианты отмечаются и отключаются, а листать можно после правильного ответа.
- В «Проверке» ученик вводит число цифровой клавиатурой под примером. Неверный ответ можно исправить или оставить и перейти дальше; итог учитывает последний ответ на каждое задание.
- В режимах «Выбери ответ» и «Проверка» счёт и сброс расположены под карточкой. Настройка озвучивания примеров и открытых ответов находится в меню `⋯`.
- Карточка примера сохраняет размер между режимами. Свайп действует только внутри неё; прогресс и локальная статистика остаются на устройстве.
- Таблица, порядок и позиция сохраняются на устройстве отдельно для каждого режима. Для «Проверки» также сохраняются отправленные ответы текущего прохода. Кнопка «Сбросить» после подтверждения начинает заново выбранный режим.
- Персональные данные ребёнка и серверная статистика не сохраняются.

## Локальная проверка

Node.js 18+. `npm ci && npm run check`. Тесты охватывают 100/10 примеров, отсутствие дублей и восстановление состояния; браузерную проверку выполняют отдельно.

## Telegram Serverless

Опубликована Serverless revision `3`: <https://app8854507045.tgcloud.ai/>. Она соответствует коду из PR #10 и исходному SHA `f972a8e989d2c2e1c3799ecf377e7556dfecf483`; фактическая публикация подтверждена в PR #12. Последующие изменения `main` нужно отдельно выпускать после безопасного preflight; GitHub merge сам по себе Telegram не обновляет.

Исходники `main` могут содержать изменения, ещё не опубликованные в Telegram. Перед выпуском новой версии следовать preflight ниже; обновление GitHub само по себе не меняет приложение в Telegram.

Перед следующим релизом выполнить `npx tgcloud fetch`, `npx tgcloud status`, `npx tgcloud diff`, проверить app ID и содержимое; затем `npm run deploy` без `--force`. После push снова выполнить fetch/status: CLI 0.2.0 может завершиться ошибкой записи локального snapshot уже после успешной загрузки.

Username бота CLI не показывает. Для подтверждения, что сохранённая CLI-связь относится к `@umnozhayka_tgbot`, владелец сверяет app ID с настройками Serverless именно этого бота в BotFather.
