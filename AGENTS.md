# Умножайка — правила разработки

- Source of truth — публичный репозиторий `dvpot/umnozhayka`, ветка `main`; любые изменения через PR с CI. Локальный проект Codex: `/home/dvpot/projects/github/umnozhayka`. До и после задачи синхронизироваться с GitHub, не перезаписывать чужие изменения.
- Перед изменениями читать `README.md`, `docs/PLAN.md`, `docs/TELEGRAM_DEPLOY.md`, `docs/BOT_PROFILE.md` и соответствующий Issue.
- Удобный русский интерфейс: фиксированная **цветная** шапка, выбор `Все`, `×1…×10`, кнопка перемешивания с подсветкой. Лишний дубль названия внутри Mini App не выводить.
- Режим `Все` — ровно 100 уникальных примеров `1×1…10×10`, отдельная таблица — 10. Перемешивание без повторений. Логика в `app/engine.js`, тесты в `tests/engine.test.mjs`.
- В «Тренировке» при просмотре примера ответ раскрывается через 10 с или нажатием на `?`. Свайп влево листает вперёд, вправо — назад. Стрелки находятся в карточке.
- В «Проверке» ответ вводится на цифровой клавиатуре под карточкой. Оценка один раз на пример, переход вперёд после оценки, возврата к оценённым примерам нет. Текущий проход сбрасывается отдельно от накопленной статистики.
- Для синхронизации «Мой прогресс» хранить только технический ключ аккаунта из проверенного Telegram-контекста и минимальное состояние обучения: счётчики примеров, числовые итоги по таблицам, один текущий проход и настройки звука. Состояние прохода перезаписывается при смене занятия. Не собирать профили детей, имена, контакты и архив прошлых ответов. Не подключать рекламу/аналитические SDK, не коммитить токены и приватные данные.
- Не публиковать на Serverless без `tgcloud fetch`, `status`, `diff` и проверки app ID `8854507045`/содержимого. Никакого `--force` без разрешения владельца. После push обязательно проверить реальную ревизию.
- Для Telegram профиля BotFather готовые изображения и тексты — в `docs/BOT_PROFILE.md`.
